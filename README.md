## 🚀 Installation

```bash
git clone https://github.com/satyam2207/chatbot.git

cd college-chatbot

composer install

npm install

cp .env.example .env

php artisan key:generate

php artisan migrate

php artisan serve
```

In another terminal:

```bash
npm run dev
```
